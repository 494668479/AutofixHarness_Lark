${message_block}

自定义 Prompt

强制输出格式

修复思路： 必填，说明判断依据、定位方向、采用或放弃的方案。

本轮处理： 必填，说明本轮实际做了什么；未修改时说明原因。

验证情况： 必填，说明已运行或建议运行的语法检查、编译、测试。

风险说明： 必填，说明可能影响范围；无明显风险则写“未发现明显风险”。

修复状态： 最后一行必须严格为“已完成”“未完成”“无法修复”三者之一。

可用占位符

{{task_info}} 任务基础信息，包含项目配置、WorkRoot、记录ID、分支、worktree 路径、修复版本和 Base 摘要。

{{source_message}} 飞书收到的原始消息内容。

{{base_fields}} 多维表格当前行的完整字段 JSON。

{{context_snapshot}} 首次 Prompt 使用的工具层上下文收集结果。

{{worktree_path}} 当前任务的 worktree 路径。

{{record_id}} 当前多维表格记录 ID。

{{branch_name}} 当前任务使用的 git 分支名。

{{workroot_name}} 当前项目 WorkRoot 名称。

{{repair_version}} 当前任务匹配到的修复版本。

{{issue_summary}} 从消息和多维表格行生成的任务摘要。

{{previous_ai_reply}} 二次 Prompt 使用的上一轮 AI 回复。

{{current_diff}} 二次 Prompt 使用的当前 git diff / status。

{{verify_output}} 二次 Prompt 使用的上一轮工具层验证结果。

{{first_prompt}} 二次 Prompt 可引用的首轮 Prompt 原文。

如果提示词中没有使用占位符，系统会在末尾自动追加任务信息、原始信息、Base 行字段、上下文快照，以及二次 Prompt 所需的上一轮回复、当前 diff 和验证结果。
